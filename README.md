# FlowTask

A task manager that runs entirely in the browser, in a single `index.html`. The interface is in French.

## Features

- Create, edit, filter and search tasks, with categories and deadlines
- Calendar view
- Pomodoro timer and a focus mode
- Light and dark theme, with a choice of colour themes
- Everything is stored in `localStorage`, so there is no account and no server

## Run

Open `index.html` in a browser. There is nothing to install or build.
